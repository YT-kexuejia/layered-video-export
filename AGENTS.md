# Agent entry

For a request to turn a supplied talking-head video into a finished video, read `SKILL.md` and run the complete workflow. The bundled template is `templates/studio-blue/template.json`; an external template can be provided to `pipeline.py build --template DIRECTORY`.

Media, captions, scene plans, downloaded model weights, local settings and exports belong in ignored `local/` projects. Keep them out of Git. This repository distributes code and a generic style template, not the creator's video or test data. Do not make the GitHub repository public unless the user explicitly authorizes that action.
